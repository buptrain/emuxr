# Security policy

## Supported releases

Only the most recent published EmuXR GitHub Release receives security fixes.
Prereleases may be withdrawn and replaced by a newer prerelease.

## Reporting a vulnerability

Do not include exploit details, signing material, ROMs, BIOS files, or private
user data in a public issue. Use GitHub private vulnerability reporting for
this repository when it is enabled by the repository owner. Until then, contact
the repository owner privately through GitHub and include:

- affected release version and APK SHA-256;
- device and Android XR version;
- minimal reproduction steps; and
- any safe logs or proof of impact.

Do not publish a proof of concept until a fix or coordinated disclosure plan
has been agreed.
